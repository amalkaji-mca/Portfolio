# Amal K Aji | Portfolio

A modern personal portfolio website for Amal K Aji, showcasing cybersecurity expertise, software engineering work, research interests, certificates, and contact details.

This project is built as a static front-end website using HTML, CSS, and JavaScript, with a dynamic animated layout and interactive sections.

## Overview

- Cybersecurity and network defense focus
- Android and Flutter development
- Machine learning and AI product work
- Portfolio sections for work, skills, certificates, and contact
- Responsive design with animated UI effects

## Live demo

Open `index.html` in a browser to view the site locally.

## Run locally

1. Clone the repository.
2. Open the project folder.
3. Launch `index.html` in your browser.

Note: Keep the `assets` folder in the same directory as `index.html` so that images, resume files, and other media load correctly.

## Features

- Interactive tabbed navigation
- Animated hero section with dynamic typed text
- 3D-style portfolio cards and motion effects
- Skills visualisation ring
- Certificate filtering
- Copy-to-clipboard contact details
- Contact form UI for inquiries
